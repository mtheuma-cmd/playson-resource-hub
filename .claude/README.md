# .claude

Context for AI-assisted work on the Playson Resource Hub. These files are version controlled. They describe architecture and commands. They must not contain secrets, credentials, personal data, or internal hostnames.

## Required files

- `context.md` — architecture and design decisions
- `quick-ref.md` — commands and the publish flow
- `README.md` — this file

## When to update

Update `context.md` when routes, the catalog, or the deck player architecture changes. Update `quick-ref.md` when commands or the publish steps change.

## Maintainer

The team that owns this repository.
